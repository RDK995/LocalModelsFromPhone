TASK M19b-T3 — Hard wall-clock cap on thinking-off research calls; thinking guard on plan and write with one think:false re-issue (FR42 time limits)

Routing: tier Top, model opus, reason_code DIFFICULT_CONCURRENCY — a per-attempt cancellation
timer must compose with the run's existing three abort sources (hard Stop `signal`, FR38
`stopSignal`, FR36 phase deadlines) without misclassifying one as another; a misclassified abort
either ends a run that should carry on or retries a call the user stopped, and both are hard to
detect.

Goal:
Every thinking-off research model call has a hard wall-clock cap (setting `routineCapMs`, default
30000). A call still running at its cap is cancelled (its HTTP request aborted) and counts as a
failed attempt under FR35's retry-then-skip rule (the step retries up to `retries` times, then is
skipped and the run carries on). Plan and write (thinking on) run under a thinking guard (settings
`planGuardMs` default 30000, `writeGuardMs` default 60000): if no answer content has arrived by the
guard (the model is still thinking), the request is cancelled and re-issued exactly once with
`think: false`. Once answer content has started arriving the guard no longer applies — an answer is
never truncated. The re-issue carries no `num_predict` (so it cannot truncate a report) and no
routine cap; it is bounded only by the phase deadline. If the re-issue also fails (error, invalid
JSON, failed validation), the step returns null with no further retries, and the existing FR35 skip
rule (plan -> `[brief]`) or FR36 write-up rules (no report -> gathered notes / NO_REPORT_NOTE, run
`partial`) apply, so the run still ends `complete`, `partial` or `failed`.
