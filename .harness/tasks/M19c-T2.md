TASK M19c-T2 — The deep research note step sends a passage excerpt (page first, task last, byte-stable system prefix) and skips empty/blocked pages without a model call (FR43, M19c-AC1..AC3)

Routing: tier Mid, model sonnet, reason_code ORDINARY_IMPLEMENTATION — wires an existing pure module
(T1) into the research loop and moves per-step task text out of the system message; touches existing
test fixtures, with a clear HTTP-level test oracle; no new concurrency.

Goal:
In a deep research run, the note call for a read page receives only the page title, its first
paragraph and the top BM25 passages (via `buildNoteExcerpt` from T1), placed FIRST in the user
message, with the task text LAST in the user message; every step's system message is the same
byte-stable fixed instruction text. A page that `buildNoteExcerpt` marks "empty" or "blocked" gets no
note call and one structured log line. Quotes are still checked against the FULL stored page text,
and raw page text is still never carried into later requests.
