Goal:
In the phone app, the source list at the end of a web answer starts collapsed behind a header
"Sources (n)" (n = number of sources) that expands and collapses on tap; the expanded state is
component state only (never saved, so a reopened chat shows it collapsed). When expanded, each
source is its own separate tappable entry showing its site logo (FR27 SourceLogo, globe fallback)
followed by its page title, and tapping the entry opens that source's saved URL in Safari (the
existing handleOpenSource / Linking.openURL). Distinct sources are never merged into one link.

Design:
1. New pure module mobile/src/ui/sourceList.ts (no React imports) holding the list's view-model, e.g.
   `sourceListHeader(sources) -> "Sources (n)"` and `sourceListEntries(sources) -> Array<{ key,
   title, url, host }>` with exactly one entry per saved source, in saved order, never merged or
   de-duplicated (two sources on one host = two entries, same host; two sources with identical URL
   are still two entries with distinct keys), title via sourceLabel (whitespace/newlines collapsed so
   one entry is one line of label), host derived the same way as FR27 logos (null/unusable host ->
   globe). A pure toggle helper for the expanded state is fine (e.g. `initialSourcesExpanded = false`,
   `toggleSourcesExpanded`). No list when sources is empty/absent (keep current behaviour for replies
   with no sources).
2. New component mobile/src/ui/SourceList.tsx: `SourceList({ sources, iconCache, onOpenSource })`.
   Header is a TouchableOpacity (accessibilityRole "button", accessibilityState expanded) showing
   "Sources (n)" plus a small chevron/indicator; `useState(false)` for expanded (not persisted
   anywhere). When expanded, each entry is its own TouchableOpacity (accessibilityRole "link") laid out
   as its own row (a View block, flexDirection row) containing the logo and the title Text; onPress
   opens that entry's url. Entries must be separate block-level touchables, never Text nodes nested
   inline inside one shared Text (inline nesting is how several links run together into one tappable
   paragraph). The logo in a row may be SourceLogo or a non-pressable variant; if you add a prop to
   SourceLogo, keep the FR27 inline behaviour unchanged.
3. chat.tsx: replace the lines ~428-443 block with `<SourceList sources={item.sources}
   iconCache={iconCacheRef.current} onOpenSource={handleOpenSource} />`; remove styles that become
   unused; keep sourceLabel import only if still used.
