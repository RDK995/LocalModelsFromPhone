Goal (Red -> Green -> Refactor):
1. Anchor: when a server event carrying `elapsed_ms` and `budget_ms` is applied, record the local
   receive time with it: e.g. `clock?: { elapsed_ms; budget_ms; anchored_at }` where `anchored_at` is
   the local ms time the event was applied. Give `applyStreamEvent` an optional third parameter
   `now: number` (default `Date.now()`), so existing callers keep working. Every such event re-anchors
   (replaces elapsed_ms and anchored_at) — including events that arrive after a resume. Use the
   server's value as given (no client-side "never go backwards" logic).
2. Projection: a pure exported function in src/ui/deepResearch.ts, e.g.
   `liveResearchElapsedMs(clock: { elapsed_ms; budget_ms; anchored_at }, now: number): number`
   = min(budget_ms, elapsed_ms + max(0, now - anchored_at)).
3. Ticker: a pure exported helper in src/ui/deepResearch.ts, e.g.
   `startSecondTicker(onTick: () => void, timers = { setInterval, clearInterval }): () => void` that
   calls onTick every 1000 ms and returns a stop function that clears the interval.
4. View-model: `buildChatItems(persisted, pending, now?: number)` (default `Date.now()`): the pending
   streaming item's `clockLabel` uses `liveResearchElapsedMs(acc.clock, now)` against `budget_ms`;
   when `acc.research` (the done event's final result) is present it is shown as-is, as today.
5. Screen: in src/app/chat.tsx keep a `now` state; while a pending, non-blocked reply has
   `accumulator.clock` and no `accumulator.research`, run `startSecondTicker(() => setNow(Date.now()))`
   in a useEffect and stop it in the cleanup; pass `now` to `buildChatItems`; pass `Date.now()` to
   `applyStreamEvent` in onEvent.
6. Tests (new or extended, under src/ui/): (a) with an anchor of elapsed 10 000 ms at t0, labels at
   t0+1000, t0+2000, t0+3000 read 0:11, 0:12, 0:13 of the budget; (b) the projection never exceeds
   budget_ms (e.g. anchor 479 000 of 480 000, 5 s later shows 8:00 of 8:00); (c) a new step event
   re-anchors: after ticking past the old anchor, an event with a new elapsed_ms makes the label read
   from the new value at that moment; (d) re-anchor after a resume: drive events through
   `applyStreamEvent` in the order a dropped-then-resumed stream delivers them (events before the drop,
   a gap of local time with no events, then the first event after the resume) and assert the label
   follows the post-resume event's elapsed_ms; (e) the ticker calls onTick on each 1000 ms interval
   with fake timers and stops after the stop function; (f) ordinary replies (no clock) get no clockLabel.
