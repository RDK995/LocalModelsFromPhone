When any chat send gets a 401 from the server (from GET /v1/state or from POST /v1/chat), the app shows an
alert titled "Password wrong or changed" and navigates to the Settings screen with the token form already
open. It must not show the generic "Error" alert for a 401.

  or delivered to the `onError` callback passed into `client.chat()`. Every other error still goes to
  `onError` unchanged; the existing `ModelNotResidentError` -> `onBlocked` behaviour is unchanged.
