TASK M22-T4 — Deep research reads the next unread search result in place of each unreadable page

Routing: tier Top, model opus, reason_code DIFFICULT_CONCURRENCY — replacement reads start inside FR44's
parallel prefetch and must respect FR36's deadline, Stop and the page quota without double-reading or
leaving an un-awaited read; a mistake shows up as a hang or a missing page rather than a failing assertion.

Depends on: M22-T3 accepted (read() returns `unreadable`; noteNext logs and skips it).

Goal:
In server/src/generations/research.ts, when a prefetched read comes back unreadable, the page does not
use up its sub-question's page slot: the next unread URL from that sub-question's EXISTING search
results (`sq.candidates`, in their search order, skipping any URL already read or reserved in the run
via `readKeys`/`pageUrlKey`) is started immediately in its place, as a prefetched read with its own
started read step (FR45), while the research deadline allows. No search and no "Choosing pages" model
call is made for a replacement.

- FR47(a) (.harness/requirements.md lines 400-414), FR44, FR36, FR45; edge cases lines 744-753.
- Architecture C6 (.harness/architecture.md lines 112-118); D-M19-1 (line 578 onwards, Stop).

Design decisions already taken (do not reopen):
- "Next unread URL" = first entry of `sq.candidates` (search result order) whose `pageUrlKey` is not in
  `readKeys`. Reserve it in `readKeys` when started (as choosePages does). `sq.reads` is NOT incremented
  for a replacement (the unreadable page's slot passes to it).
- Call `checkDeadline()` before starting a replacement; if the phase is over, start nothing (the run moves
  on as it does today when the deadline passes). Use `startRead` so the replacement is in `started` and
  is covered by the one phase signal, the end-of-run drain and Stop.
- The replacement is appended to `sq.prefetched`; `noteNext` keeps looping, so it is noted in turn.
- Each page is judged on its own; no site is remembered as blocked.
- If candidates run out, the sub-question simply has fewer pages; no gap check or search is triggered by
  the replacement logic itself (later-round behaviour is otherwise unchanged).
- A run with no notes already ends `failed` with the plain sentence (research.ts ~1106-1141); confirm it
  holds when every page is unreadable.
