   - `ChatItem` gains optional `steps?: StepEventData[]` and `sources?: {title: string; url: string}[]`, present only when non-empty.

   - resident's model found in `models` with `tools: true` → `{ enabled: true, explanation: null }`

   - resident not found in `models` (or models null) → `{ enabled: false, explanation: "Can't tell whether <name> supports web search." }`
   Pure function, no React imports.
