Goal:
Create server/src/generations/quoteMatch.ts exporting:

  export function normaliseForQuote(s: string): string
  export function quoteOnPage(quote: string, normalisedPageText: string): boolean

`normaliseForQuote` applies, in this order:
  1. Unicode NFKC (`s.normalize("NFKC")`). This also turns "…" into "..." and non-breaking spaces into spaces.
  2. Markdown to visible text: an image `![alt](target)` becomes `alt`; a link `[text](target)` becomes
     `text` (image before link, so `[![alt](img)](href)` ends as `alt`); emphasis markers are removed —
     every `*` character, every `~~`, and `_` / `__` / `___` runs that open or close emphasis (an
     underscore run touching whitespace, punctuation or the string edge on one side and a non-space
     character on the other). An underscore inside a word (`snake_case`) is kept.
  3. Quotes and apostrophes alike: ‘ ’ ‚ ‛ ′ ` ´ become `'`; “ ” „ ‟ ″ « » become `"`.
  4. Dashes alike: U+2010 ‐, U+2011 ‑, U+2012 ‒, U+2013 –, U+2014 —, U+2015 ―, U+2212 −, U+FE58 ﹘,
     U+FE63 ﹣, U+FF0D － all become `-`.
  5. Lower case (`toLowerCase()`).
  6. Whitespace collapsed to one space and trimmed.

`quoteOnPage(quote, normalisedPageText)`: the caller passes the page text ALREADY normalised with
`normaliseForQuote` (so a page is normalised once, not once per note). The quote is normalised; then:
  - if the normalised quote contains no run of three or more dots, it matches when
    `normalisedPageText.includes(normalisedQuote)`;
  - otherwise it is split on `/\.{3,}/` into pieces; each piece is trimmed and empty pieces are discarded;
    it matches when every piece is found in order — piece k searched with `indexOf(piece, from)` where
    `from` is the end of piece k-1's match. A quote whose pieces are all empty (e.g. just "...") does
    NOT match.
  - an empty normalised quote does NOT match.
