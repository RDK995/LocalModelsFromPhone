TASK M10c2-T1 — Tier: Cheap (haiku). Routing: reason_code BOUNDED_LOW_RISK — small pure functions with stated inputs and outputs, fully unit-testable.

Goal:
A new pure module `mobile/src/ui/sourceLinks.ts` decides, for a markdown link URL in an assistant answer, whether it matches one of that reply's saved sources, and gives the normalised site host used to ask the Mac for that site's logo.

Relevant Requirements:
- FR27 (.harness/requirements.md lines 130-144): a markdown link whose URL matches one of that reply's saved sources gets a logo; matching tolerates trivial differences (scheme http/https, a leading `www.`, a trailing slash). Any other link — a URL not in the sources, a truncated/made-up URL such as `https://www.msn.com/...`, or any link in a reply that has no sources — is plain text.
- Architecture D-M10c-2 (.harness/architecture.md `### D-M10c-2`): icons are keyed by normalised host (lower-case, leading `www.` stripped).

Acceptance Criteria:
- Export `type LinkSource = { title: string; url: string }` (same shape as `sources` items in mobile/src/ui/chatItems.ts line 40).
- Export `normaliseLinkUrl(url: string): string | null`: trims; accepts only `http:` / `https:` URLs (anything else, or unparseable, -> null); result drops the scheme, lower-cases the host, strips one leading `www.` from the host, keeps port, path, query (fragment dropped), and removes one trailing `/` from the path (so `https://www.Example.com/a/` and `http://example.com/a` normalise equal; `https://example.com/` and `example.com` root normalise to `example.com`). Do not rely on the global `URL` class being complete — React Native's URL is partial; implement parsing with a regex / string ops (scheme, authority, rest).
- Export `matchSource(url: string, sources: LinkSource[] | undefined): LinkSource | null`: returns the first source whose normalised url equals the link's normalised url; null when sources is undefined/empty, when the link does not normalise, or when nothing matches. `https://www.msn.com/...` against sources without it -> null. Query must match exactly (a different query is a different page).
- Export `siteHost(url: string): string | null`: the normalised host (lower-case, leading `www.` stripped, no port) of an http(s) URL, else null.
- Tests in `mobile/src/ui/sourceLinks.test.ts` (bun:test, style of mobile/src/ui/chatItems.test.ts) covering: scheme variant, www variant, trailing-slash variant, case of host, msn truncated URL not matched, no sources, undefined sources, non-http link (`mailto:`, `javascript:`) -> null, different path not matched, siteHost cases.
- Red first: write the tests, see them fail, then implement.
