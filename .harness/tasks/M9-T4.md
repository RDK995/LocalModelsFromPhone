Goal:
When a /v1/chat request has `web:true`, the generation manager (C6) runs an Ollama tool-calling loop: it prepends the current-date system note, offers `web_search`/`read_page` while fewer than 10 tool calls have run, executes each call through the web tools (C12), streams `step` events and one `sources` event before `done`, and after the 10th call withdraws the tools so the model gives its answer. With `web` absent or false, behaviour is exactly as today: no tools, no system note, no web-tools call.

- FR18 (lines 76-80): with the switch off the reply makes no search or page request of any kind.
